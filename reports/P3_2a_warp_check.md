## Design

- R = 200 outer replications; replication r is `sim.synthetic_panel(1013, b=0, tails="t5", seed=s_r)`.
- Seeds: s_r = spec seed + 4,100,000 + r; warp s_r + 50,000; inner s_r + 60,000 (spec seed 20261001).
- Per replication: t_r from `calib.fit_t` (target `abn_oc`); one warp-speed resample giving t*_r; a full inner bootstrap of B = 99 resamples giving p_r = (1 + #{|t*| >= |t_r|}) / (B + 1); the full test rejects if p_r <= 0.05. Every fit's DK lag is 6 (asserted).
